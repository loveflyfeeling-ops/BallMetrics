勝率模型如何運作

・Elo 評分：以歷史戰績替每隊計算實力分數，含主場優勢、比分差距、換季回歸，參數用網格搜尋自動挑選，並以「最後一季」做樣本外驗證。

・國際盤共識：由 The Odds API 取得多家國際博彩公司賠率，各自去水後平均。國際盤（尤其 Pinnacle）通常比任何單一模型都準。

・混合：賽事設為「自動」時，模型勝率 = Elo × 權重 + 國際盤 ×（1 − 權重），再拿去跟台灣運彩賠率比較找 +EV。

填入範例格式

欄位：date（日期）、away（客隊）、home（主隊）、away_score、home_score；可選 season。隊名需與賽事卡片一致。之後在系統填入的賽果也會自動加入。

參數設定

勝率模型與即時同步

・分數凱利：全凱利波動極大，建議 0.1~0.25。

・去水方法：power 會把較多抽水算在冷門方，通常比等比例更貼近實際。

・單日虧損上限：當天結算虧損達資金的此比例，系統自動停止建議（設 0 為關閉）。

本系統為統計分析工具，不保證獲利。運彩含莊家抽水，長期而言多數下注為負期望值；請量力而為，未滿 18 歲不得購買運動彩券。
